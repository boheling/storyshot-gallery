# NCBI protein BLAST — tutorial

**Request:** "Make a tutorial video for new lab members on how to use NCBI protein BLAST (blastp): paste a query sequence, choose the database, run it, and read the results (hits table, what E-value / identity mean, opening one alignment). Use human hemoglobin beta as the main example, then show a second example with human insulin so they see how results differ."

**How it was made:** an agent with the Storyshot skill (0.3.0) wrote the storyboard and rendered it once (45 min wall clock, most of it composing; 4 BLAST searches). Storyshot's maintainer then pointed two dense "scroll down" steps at specific rows (`mark` + `note`), fixed the table-column targets, and re-rendered with a later build.

**What to look at:** one action per step with its own narration, the camera following each click, callouts on the E value and identity columns, the alignment up close, a second example (insulin) for contrast, and a recap card.
